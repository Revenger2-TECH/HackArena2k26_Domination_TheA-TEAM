# HackArena2k26_Domination_TheA-TEAM
All the core stash needed to make the App, UniHub, a great success for all Colleges!!

## ❗ Problem

College students juggle multiple disconnected systems:

- Attendance on one platform
- Notices on WhatsApp or notice boards
- Assignments scattered across apps

This leads to missed deadlines, poor communication, and confusion.

## 💡 Solution

UniHub is a unified campus portal that brings all academic and administrative services into one clean platform.

It provides a personalized dashboard for students, integrates attendance, assignments, and notices, and improves communication across campus.


## 🔥 Key Features

- 📸 QR-Based Smart Attendance
- 📊 Personalized Student Dashboard
- 📢 Unified Campus Feed (Notices & Events)
- ⏰ Deadline & Attendance Alerts
- 🔐 Secure Login System


## 🛠️ Tech Stack

Frontend: React.js  
Backend: Node.js + Express  
Database: Firebase / PostgreSQL  
APIs: Google OAuth, Firebase Cloud Messaging  

## ⚙️ How It Works

1. Faculty generates a QR code at the start of class  
2. Students scan within a limited time window  
3. Attendance is recorded instantly  
4. Dashboard updates in real-time with alerts and stats
5. Many other features on the way...........
